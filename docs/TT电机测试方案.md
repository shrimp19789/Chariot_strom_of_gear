| 额定电流 | 0.3A | **≈0.3A**（带编码器版标称） |
| 堵转电流 | 3A | **≈1.1A**（带编码器版）/ **≈1.5A**（无编码器版） |

## 3. 先确认线序（**这一步过不了就别上电**）

带编码器的 TT 电机通常是 **6 根线**：**2 根动力 + 4 根编码器（VCC / GND / A / B）**。

**依据优先顺序：**
1. **电机 PCB 或线端上的丝印**（最常见，一般写着 `M1 M2 VCC GND A B` 之类）
2. **卖家给的线序图 / 商品页**
3. **实测**（见下）

**实测找动力线（不通电）：**
- 万用表 **电阻 200Ω** 档，两两测 → 找**读数最低的一对**（TT 电机绕组通常 **几欧**）
- **确认动作**：把这两根**短接**，再**手转输出轴** → 应**明显变沉**（发电制动）
- 其余 4 根就是编码器

**⚠️ 三条铁律：**
- **颜色不能猜**（各厂不同，同一厂不同批次也可能变）
- 编码器 4 根线如果误接电源电压 → **烧霍尔**；动力线误接 ESP32 引脚 → **烧板子**
- **量线时两端都拔开**再判"通/不通"（接着电机时，绕组会让很多线对都"响"，那是正常的）

## 4. 接线

### 4.1 手转阶段（**不通电，只接编码器**）

```
编码器 VCC → ESP32 3V3          ← 只用 3.3V
编码器 GND → ESP32 GND
编码器 A   → GPIO18
编码器 B   → GPIO19
动力两根    → 什么都不接（各自包绝缘悬空）
```

> 引脚选择理由：`18/19` 不接 flash、不是启动脚；**避开** `6–11`（flash）、`34–39`（只输入、无内部上拉）、`0/2/12/15`（启动脚）。

### 4.2 通电阶段（6V）

```
电源 (+) → 动力线①        （接反只是反转）
电源 (−) → 动力线②
电源 (−) → ESP32 GND       ← ⭐ 必须共地（单独一根细线）
编码器四线保持不变
```

**⭐ 上电前检查（很重要）：**
1. 动力两根之间**不是短路**（应为绕组几欧；若 ≈0Ω 或 OL 都要查）
2. **电源正极没有碰到 ESP32 任何引脚**（目视）
3. 电机已夹住、手远离转轴

## 5. 程序

**文件**：`tt_motor_encoder_test\tt_motor_encoder_test.ino`（与本文件同目录）

- ⚠️ Arduino 要求 **`.ino` 文件名 = 所在文件夹名** → **直接把整个 `tt_motor_encoder_test` 文件夹拖进 Arduino IDE**
- **不需要装任何第三方库**（只用 Arduino 核心）
- 开发板选 **`ESP32 Dev Module`**；串口 **115200**；行尾选 **「换行符」**
- 上传失败报 `Timed out waiting for packet header` → **按住板上 `BOOT` 再点上传**

**串口命令（与 MD520 版一致）：**

| 命令 | 作用 |
|---|---|
| `h` | 帮助 |
| `r` | 计数器清零并开始计时 |
| `p` | 打印当前计数（A / B / 4 倍频 / 方向符号 / 非法跳变） |
| **`c`** | **CPR 标定**：清零 → 单向手转**整 N 圈** → 输入圈数回车 |
| **`v`** | **转速模式**（用当前 CPR 换算 rpm，每 0.5 s 打印一次） |
| `s <数>` | 手动设置 CPR（**默认 585**，TT 电机 13 线 × 1:45） |
| `q` | 退出当前模式 |

> 程序**不会自动采用**标定值 —— 只打印"建议采用值"，需要你核对后手动 `s` 输入。

## 6. 手转标定（**不通电**，10 分钟）

**操作（每轮）：**
```
① 输出轴贴一小条胶带当标记
② 敲 c → 回车
③ 朝【一个方向】慢慢转【整 10 圈】（胶带回到起点才算 1 圈）
④ 停稳 → 敲 10 → 回车
```

**要做的轮次**：**正方向 2 轮 + 反方向 2 轮**（每轮先 `c` 清零；换方向前先反向轻转一点吃掉齿隙）

**判据：**

| 看什么 | 合格标准 |
|---|---|
| `A` / `B` 脉冲 | **两相都必须有**，且两者数量接近（差 ≤3） |
| `abs(4x)/A`、`abs(4x)/B` | **接近 4.000**（如 3.97–4.03）。⚠️ 看到 3.5 / 4.5 **不要判合格** |
| `非法双位跳变` | **0** |
| 方向符号 | 正方向与反方向的符号**必须相反** |
| 同方向两轮 | **CPR 应基本一致**（差异主要来自"起止对齐"） |

**预测值（不是规格，必须实测）**：
- 13 线 × 1:45 ⇒ 每输出圈 **≈585** 脉冲（单相）
- 13 线 × 1:48 ⇒ **≈624**
- 若实测是 11 线或其他 → 按实测记录，并回头核对减速比与线数口径

> ⚠️ **手转别忘了圈数**：忘了就**重敲 `c` 重来**，**不要猜数字**（那个数是 `CPR = A/N` 的除数）。
> ⚠️ **也不要用 `p` 反推圈数**（那是循环论证，算出的 CPR 恒等于你假设的值）。

**把实测的 CPR 记下来**，第 7 节的转速换算要用它。

## 7. 通电测试（6V，10 分钟）

### ⚠️ 安全（比 12V 温和，但仍要做）
- 动力两根**先确认不短路**
- **电机夹住**再通电（启动反扭矩会甩）
- 手/衣袖离转轴 ≥10cm
- 建议串 0.5–1A 保险丝

### A. 空转 5 秒
上电 → ≤5 秒断开。看：转不转、转向、有无异响/异味。
📝 记：**哪根接正极 = 从输出轴端看 顺时针 / 逆时针**

### B. ⭐ 空载转速 + 高速计数（核心）
```
① 共地接好（电源负极 ↔ ESP32 GND）
② 敲 s 585        ← 换成你第 6 节实测的 CPR
③ 敲 v            ← 进转速模式
④ 上电，连续跑 30 秒
```
**串口会打印**：
```
[转速] 3xx.x rpm   (dr=xxxx pulse / 0.50s, CPR=585.00, 非法跳变=0)
```

| 判据 | 值 |
|---|---|
| 空载转速 | **≈355rpm**（带编码器版 1:45）/ ≈245rpm（1:48 版）；**允许 ±10–15%** |
| **必须记录** | **当时的电源电压**（转速近似正比于电压） |
| **`非法跳变`** | **保持 0** |
| **rpm 稳定性** | 应稳定（波动几个 rpm 以内） |

> ⭐ **这一步同时验证"高速计数"**：355rpm、CPR 585 时 **A 相 ≈3461 沿/s** ——
> 比 MD520 的 1888 沿/s **高约 1.8 倍**，是对中断的更大考验。**若 rpm 稳定且非法跳变 0，说明计数链路在这个速率下没问题。**

### C. 空载电流
万用表 **10A 档串在电源与电机之间**（或看电源自带显示）。
- 带编码器版标称 **≈0.08A**；无编码器版 ≈0.2A
- 明显偏大（比如 >0.5A）→ 记录并查（摩擦大/绕组问题）

### D. 温升
连续空载 **2 分钟** → **先断电再摸**（手背轻碰外壳）：
- **温热（能一直贴着）** ≈40–50℃ → ✅ 正常
- **贴 2 秒就想缩手** ≈60℃ → ⚠️ 记录
- **烫到不敢碰** → 🔴 异常

### E. 换向
断电 → **交换两根动力线** → 上电 → 应**反向转** ✅

### F. 堵转电流（可选，**只有电源能提供 ≥1.5A 才做**）
轻压/卡住输出轴 **<0.5 秒**，读峰值。带编码器版标称 **1.1A**。
⚠️ **只做一次**；优先读电源自带显示（便宜万用表的 10A 档常无保险丝）。

## 8. 如果你的是「不带编码器」的 TT 电机

**手转数脉冲的方案不成立**（没有脉冲输出）。可用的替代方法：

| 方法 | 怎么做 | 能得到什么 |
|---|---|---|
| ⭐ **手机慢动作视频** | 拍 10 秒高速慢动作（240fps），回放数圈数 | 粗算 **rpm**（±10% 量级） |
| **反电动势旁证** | 万用表**直流 mV/V 档**接两根动力线，**用手转轴** → 应看到电压 | 绕组/碳刷是否正常（定性） |
| **空载电流** | 串电流表，6V 空载 | 典型 0.1–0.25A；明显偏大 = 异常 |
| **齿轮箱手感** | 手转输出轴 | 有无卡顿点、异响、旷量 |
| **堵转电流** | 短暂卡住（<0.5s） | 典型 1.5A；与标称比 |
| 要精确转速 | 加装光电/霍尔测速片，**或直接换成带编码器版本** | 精确 rpm |

## 10. 故障排查

| 现象 | 先查（**按顺序，别跳**） |
|---|---|
| 串口什么都没有 | ① 波特率 115200？② 端口选对？③ **按板上 `EN` 键**（程序只在开机打印横幅） |
| 手转时两相都是 0 | ① 编码器 3.3V 供电在不在、插头松不松 ② 线序（丝印/卖家图）③ 换 GPIO 复测 ④ 交换 A/B ⑤ 用已知信号源验证采集通道 |
| 只有一相有脉冲 | 同上 ①–⑤；**确认缺失与引脚无关**后才可判"缺通道" |
| 手转正常、通电后计数乱 | ① **动力线与信号线太近**（分开走）② 共地接触不良 ③ 电源噪声大 |
| 通电后电机转但 rpm = 0 | ⭐ **没共地**（电源负极 ↔ ESP32 GND 那条线） |
| 电机不转 | ① 电源有没有电（量电压）② 动力线通不通 ③ **电源保护了**（小电源带不动启动） |
| 转速换算明显不对 | ⚠️ `CPR` 填错了 —— 回到第 6 节实测量值 |
| 数值偶尔跳一下 | 手转一圈里混入了反向（`q` 会加加减减）；或接触不良 |

## 11. 安全红线

1. 🔴 **TT 电机是 3–6V 器件 —— 接线前先确认电源电压，绝不要直接上 12V**
2. 🔴 **编码器只用 3.3V**（官方支持 3.3–5V，但 3.3V 最安全）；**电源正极绝不进 ESP32**
3. 🔴 **改线前先断电**；不插拔通电中的线
4. 🔴 **电机必须夹住**再通电
5. ⚠️ 摸温度要**先断电**再摸（用**手背**，更敏感也更安全）
6. ⚠️ 闻到焦味 / 冒烟 → 先断电源再拔线
