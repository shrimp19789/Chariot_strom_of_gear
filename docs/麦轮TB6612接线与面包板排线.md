# 四麦轮：双 TB6612FNG 两线法接线与面包板排线

更新：2026-10-06。采用[两线法备选方案](麦轮TB6612接线-两线法备选方案.md)的 GPIO 与排号，配套 [面包板.xlsx](assets/面包板.xlsx)。**本版取代旧三线法方案，无需 IO 扩展器或第二块主控。** 目前仅完成设计核对，未通电、烧录或实物验收。

## 1. 方案与适用条件

每轮用 IN1、IN2 两根 GPIO 控制方向和调速，驱动板 PWMA/PWMB 固定接 3.3V。四轮共 8 根，加两板共用 STBY 共 **9 根输出**。底盘单测与全车集成使用同一张表，原 PS2Catapult 接线不变。

适用于 GPIO16/17 可用的经典 ESP32-WROOM 类板，须核对实物引出及占用；不能直接套用 ESP32-S3/C3 或 GPIO16/17 被 PSRAM 占用的板型。保留串口 GPIO1/3、BOOT GPIO0，排除 Flash GPIO6–11、仅输入 GPIO34–39 后，本方案没有预留新的舵机信号脚。需要舵机时另行规划，不能接 TB6612 输出。

先单测底盘，断开投掷动力并卸除可能运动的负载；通过后再集成。底盘控制不经过 I2C，但投掷仍依赖 AS5600，已有 SDA 接触故障仍须修复。现有 MotorDriver/MotorLinkCheck 的 QGPMaker 接口不能驱动本接法，PS2Catapult 也尚未加入底盘控制。

## 2. 全车 GPIO 与四轮对应

从车顶看，D1 在左侧，D2 在右侧；FL=左前、RL=左后、FR=右前、RR=右后。

| 设备/车轮 | 引脚 | ESP32 GPIO / 接法 |
|---|---|---|
| D1-A 左前 FL | AIN1 / AIN2 | 16 / 17 |
| D1-B 左后 RL | BIN1 / BIN2 | 18 / 19 |
| D2-A 右前 FR | AIN1 / AIN2 | 23 / 32 |
| D2-B 右后 RR | BIN1 / BIN2 | 15 / 5 |
| 两板共用待机 | STBY | 33，外加 10kΩ 到 GND |
| 两板 A/B 通道使能 | PWMA / PWMB | 四个脚全部接 3.3V，不占 GPIO |
| 两板逻辑电源 | VCC | 3.3V |
| AS5600（原接线） | SDA / SCL | 21 / 22 |
| DRV8313（原接线） | IN1 / IN2 / IN3 / EN | 25 / 26 / 27 / 14 |
| PS2（原接线） | CLK / CS / CMD / DAT | 2 / 4 / 12 / 13 |

D1 AO1/AO2 接 FL，BO1/BO2 接 RL；D2 AO1/AO2 接 FR，BO1/BO2 接 RR。商品图的 A01/B01 指 AO1/BO1。每对输出只接一台电机的两根动力线，**输出不接 GND、不并接两个轮子、不接编码器线**。

正方向定义为该轮驱动车体向前。逐轮点动确定极性，必要时对调该轮电机线或在固件中反向；左右轮不能仅凭外侧观察的顺逆时针判断。横移另需核对麦轮左右手安装位置。

GPIO15、5 是启动配置脚，不能把默认上拉当作可靠制动保证。TB6612 输入内置弱下拉，模块外围也影响电平，必须实测冷启动及下载。原 PS2 的 GPIO2/12 也有启动限制；若需改线，必须重新统一分配，不能照旧固件注释改到已占用的 18/23。STBY 固定使用非启动配置脚 GPIO33。[ESP32 引脚依据](https://documentation.espressif.com/esp32_datasheet_en.html)。

## 3. 两线法的输出行为与固件要求

下表驱动板 PWM 脚始终为高，H=3.3V，L=0V；表中 PWM 波形输出在 IN 脚上。

| 动作 | STBY | IN1 | IN2 | 输出行为 |
|---|---|---|---|---|
| 待机/故障禁用 | L | 任意 | 任意 | 高阻，电机可滑行 |
| 正向调速 | H | PWM 波形 | L | 驱动与滑行交替 |
| 反向调速 | H | L | PWM 波形 | 反向驱动与滑行交替 |
| 滑行停止 | H | L | L | 高阻 |
| 主动短路制动 | H | H | H | 两输出拉低，短接电机两端制动 |

占空比控制驱动比例，**不等于平均转速，也不保证转速与占空比线性**。两线法仍可主动制动，本表调速方式在 PWM 低期间滑行。STBY 拉低会退出制动，不能把待机当成机械抱死。

固件实现要求：

1. 启动先保持 GPIO33 低；配置八个 IN 输出及 PWM 初值为 0，检查控制输入后，明确使能才将 STBY 拉高。
2. 可按八个 IN 各分配一路 PWM 资源。须核对实际 Arduino 核心和 SimpleFOC 所用 LEDC/MCPWM 后端、定时器及频率，不能直接用“8+3≤16”证明无冲突。
3. 换向先撤去原方向 PWM，使两 IN 都低，按电机负载允许的减速过程再启用另一方向。制动时确保 PWM 外设实际输出常高，不能只向仍被 PWM 接管的脚调用 digitalWrite。
4. 停止测试、控制帧超时、通信断开及集成故障处理均应拉低 STBY；看门狗复位也需实测。下拉不能压住程序卡死时仍主动输出的高电平，保留硬件断电开关。
5. 四轮分别混控；旧 `DRIVE 左 右` 差速接口不足以实现完整麦轮运动。

**本方案必须安装 STBY 外部 10kΩ 下拉**，确认模块无将 STBY 硬接高的焊桥。芯片本身已有约 200kΩ 下拉，外加电阻用于强化默认禁用；不采用“所有 GPIO 启动时都悬空且持续固定毫秒数”的假设。共用下拉须与两板 STBY 连通；桥线断开时不能声称两板仍都受此电阻保护。

## 4. 电源和大电流走线

| 节点 | 接法 |
|---|---|
| 左 + 轨 | ESP32 3V3；分配两板 VCC 与四个 PWM 常高脚 |
| 右 + 轨 | 留空、无电，不分配 5V，不与左 + 轨桥接 |
| 左右 − 轨 | GND，桥接后仅作逻辑地分配 |
| 两板 VM | 按电机额定电压及商品模块 3–12V 范围选电源，经保险丝/物理开关/端子分别供电 |
| 两板功率 GND | 各自用电源线直接回公共地端子，再与 ESP32/降压模块共地 |
| AO1/AO2、BO1/BO2 | 直接到电机，不经面包板或细杜邦线 |

VCC 用 3.3V。芯片规格为 2.7–5.5V，VIH 最小 0.7×VCC；VCC=5V 时不能保证接受 ESP32 的 3.3V 高电平。商品图标 VCC=5V，芯片支持 3.3V，但仍需核对模块并实测。1.2A 不是任意板型可持续输出的保证，3.2A 是限定条件下的短脉冲值，须结合工作范围、散热和双通道负载核算。电机额定/堵转电流未知，当前不能确认驱动板与电机匹配。[东芝手册，第 2–5 页](https://toshiba.semicon-storage.com/info/datasheet_en_20141001.pdf?did=10660)。

```text
动力正极 → 保险丝 / 物理断电开关 → 分线端子 → D1 VM、D2 VM
动力负极 → 公共地端子 → D1功率GND、D2功率GND、降压GND、ESP32 GND
ESP32 3V3 → 左 + 轨 → 两板 VCC、两板 PWMA/PWMB
GPIO33 → 共用 STBY → 10kΩ → 逻辑地轨
```

两板和 ESP32 固定在面包板旁，用短逻辑线接入；下面排号不是 TB6612 模块排针物理顺序，不能按表将整板插入。电机线成对绞合并远离编码器线；核对模块去耦，按手册在驱动电源附近布置去耦电容。

USB 调试时断开降压输出到 ESP32 5V/VIN 的线，避免两路电源直接并联。DRV8313 动力供电仍按其要求选择，不能因同叫 VM 就随意共用麦轮电源。AS5600 供电和上拉须核实，SDA/SCL 上拉应到 3.3V，不能未经确认接 5V。

## 5. 面包板孔位表

先断电测量：同排 a–e 相通、f–j 相通，中央隔槽两边不通，不同排不通。电源轨若中间断开，只跨接同一根同电位轨的两段。Excel 行号比物理排号大 1：a3=Excel D4，e3=H4，f3=J4，j3=N4。

| 物理排号 | 左组 a–e：D1 | 右组 f–j：D2 |
|---:|---|---|
| 3 | GPIO16→a3；e3→AIN1（FL） | GPIO23→f3；j3→AIN1（FR） |
| 4 | GPIO17→a4；e4→AIN2 | GPIO32→f4；j4→AIN2 |
| 5 | GPIO18→a5；e5→BIN1（RL） | GPIO15→f5；j5→BIN1（RR） |
| 6 | GPIO19→a6；e6→BIN2 | GPIO5→f6；j6→BIN2 |
| 7 | GPIO33→a7；b7→D1 STBY；c7经10kΩ到地 | e7–f7跳线；j7→D2 STBY |
| 8 | 左3.3V轨→a8；e8→D1 PWMA | 左3.3V轨另取一孔→f8；j8→D2 PWMA |
| 9 | 左3.3V轨→a9；e9→D1 PWMB | 左3.3V轨另取一孔→f9；j9→D2 PWMB |
| 13 | GPIO21→a13；e13→AS5600 SDA | 留空 |
| 14 | GPIO22→a14；e14→AS5600 SCL | 留空 |
| 1–2、10–12、15–30 | 留空 | 留空 |

**只在第 7 排用 e7–f7 跨槽桥接。** 第 8、9 排按表分别从左电源轨取电，不额外跨槽。右 + 轨全程留空。

电源轨孔位按邻近物理排号标识：左 + 第2孔接 ESP32 3V3，第3/4孔接 D1/D2 VCC，第8/9孔接 a8/a9，第10/11孔接 f8/f9。左 − 第2孔接 ESP32 GND，第3孔桥接右 − 第3孔，第7孔接 c7 的 10kΩ 电阻另一端，第12孔接公共地端子。**每根线独占一个孔，禁止地轨承担电机回流。** 实物轨孔位置不同则选邻近空孔，以已测连通网络为准。

若已按旧版接线，断电后重排第3–9排，拆除旧 GPIO25/26/27/14 到 PWM 的线，拆除旧 GPIO4 STBY 和 e6–f6 桥。这些 GPIO 恢复原投掷/PS2 用途。旧独立底盘表和旧扩展器表均不再适用。

## 6. 分步验收

1. **断电**：逐线核对孔位与 GPIO，无 VCC/VM 混接，无输出接地，无 3.3V/GND 短路；核对第7排桥线、10kΩ及全部轨段通断。核实电机电压、堵转电流与电源限流。
2. **仅逻辑供电，VM 断开**：两板 VCC 和四个 PWM 脚约 3.3V，两板 STBY 约 0V。检查冷启动、复位、下载均保持禁用。此阶段不能用电机不转判断驱动失效。
3. **适配固件准备好后**：四轮架空、投掷动力断开，使用合适电压的限流电源。先给 VM 且 STBY 保持低确认不转，再逐轮短时低占空比点动；记录轮位、方向、电流、温升。
4. 分别验证两 IN 低的滑行、两 IN 高的制动、STBY 低的待机。制动先低速验证，不期待瞬间抱死；换向按减速过程测试。
5. 验证停止命令、PS2断联、复位会撤销使能，物理断电开关有效。单测通过后再验前后、横移、旋转；集成投掷前修复 SDA 故障并检查互锁。
