# 四麦轮：双 TB6612FNG 接线与面包板排线

日期：2026-10-06。依据：`assets/cf740fe5e1c7d5f88c907b9585950989.jpg`（TB6612FNG 商品引脚图）、`assets/面包板.xlsx`（a–j、1–30、两侧 +/− 轨）、当前 PS2Catapult 固件。以下为设计方案，尚未实物通断、供电或电机验收。

## 1. 先确定接线范围

新增两块板都是 **TB6612FNG 双路有刷直流电机驱动板**。四个麦轮各用一个 H 桥，不能两轮并接。它们与原先文档中的奇果派 PCA9685/I2C 板接口不同；现有 `MotorDriver` / `MotorLinkCheck` 固件不能直接控制它们。

本方案给出两步：

1. **现有 ESP32 单独调底盘**：暂时断开投掷驱动控制线和 PS2 信号线，按下表接四轮；无需为此增加主控。编码器 21/22 可以保留，投掷功率断开。
2. **底盘与投掷一起运行**：保留旧引脚，增加 I2C IO 扩展器或第二块主控。不能把下面的底盘 GPIO 表直接叠加到旧投掷接线上。

原因：四轮独立控制需 8 根方向线 + 4 根 PWM + 共用 STBY = 13 根输出；原投掷驱动 4 根、PS2 4 根、编码器 I2C 2 根，共需 23 根。经典 ESP32 的 GPIO34–39 只能输入，6–11 用于 Flash；保留串口、避开启动配置脚后无法直接满足。面包板增加分线位置，不会增加 GPIO。

## 2. 两板与四轮对应

从车上方看，车头向前；D1 放车体左侧，D2 放右侧，电机线走就近一侧。

| 驱动板 | 通道 | 输出端 | 车轮 |
|---|---|---|---|
| D1 左板 | A | AO1 / AO2 | 左前 FL |
| D1 左板 | B | BO1 / BO2 | 左后 RL |
| D2 右板 | A | AO1 / AO2 | 右前 FR |
| D2 右板 | B | BO1 / BO2 | 右后 RR |

图上的 `A01/B01` 是输出 `AO1/BO1`。每个输出对只接对应电机的两根电源线，**任何输出端都不要接 GND**。如电机有编码器附加线，不能把它们接到 H 桥输出。

电机方向以“该轮使车体向前”的转向为正，不以从外侧观察的顺/逆时针判断；左右电机常需要不同极性。逐轮点动后对调该轮两根线或在代码中取反。横移还取决于左右手麦轮安装位置，应核对轮组装配图。

## 3. 电源接法（两板相同）

| 引脚 | 接哪里 | 说明 |
|---|---|---|
| VCC | ESP32 3V3 分配轨 | 两板逻辑电源用 3.3V |
| VM | 适合麦轮电机额定电压的动力电源正极 | 独立分支，按商品模块限制不超过 12V |
| 所有 GND | 公共地 | VM 负极、ESP32 地、降压模块地必须相通 |
| STBY | 共用控制信号 | 低=待机；3.3V 高电平=允许工作；建议加 10kΩ 下拉到 GND |

**不要照商品图把 VCC 和 STBY 接 5V 后再用 ESP32 3.3V 直接控制。** 芯片 VCC 工作范围 2.7–5.5V，高电平门限最小为 0.7×VCC；VCC=5V 时需至少 3.5V。VCC=3.3V 可匹配 ESP32。依据：[东芝 TB6612FNG 数据手册](https://toshiba.semicon-storage.com/info/datasheet_en_20141001.pdf?did=10660)。

商品标称单通道 1.2A，不能把短时峰值当持续能力。麦轮电机额定电压、启动/堵转电流尚未提供，故尚不能确认这两板适配电机；定电源和保险丝前先查电机参数。电源还需承受四轮同时启动。

```text
动力电源 + → 保险丝 / 物理断电开关 → 分线端子
                                     ├→ D1 VM
                                     ├→ D2 VM
                                     └→ 降压模块 IN+（满足其输入范围）
动力电源 − → 地分线端子 ────────────────┬→ D1 GND（独立回路）
                                     ├→ D2 GND（独立回路）
                                     └→ 降压 GND / ESP32 GND / 逻辑地轨
ESP32 3V3 → 面包板 3.3V 轨 → D1 VCC / D2 VCC
```

两板 VM、功率地和四对电机线用合适的电源线/焊接转接端子，**不经面包板弹片或细杜邦线**。不要让电机回流先经过面包板再回电池。板子固定在面包板旁边，用逻辑排线接入；暂不建议将整板插进面包板后由面包板取电或接电机。

TB6612 电机供电与原 DRV8313 功率供电分别按各自要求选择；不能因都叫 VM 就共用任意电压。原 DRV8313 要求 8.2–24V，若麦轮电源更低则不能直接给它供电。

## 4. 底盘单独调试 GPIO 表

适用于实测经典 ESP32-WROOM 类主控；按 GPIO 丝印接，不按排针序号或 ESP32-S3 图接。GPIO16/17 是否引出及是否被板载器件占用仍需核对实物。

| 信号 | D1 左板 GPIO | D2 右板 GPIO |
|---|---:|---:|
| PWMA（前轮调速） | 25 | 27 |
| AIN1 | 16 | 23 |
| AIN2 | 17 | 32 |
| PWMB（后轮调速） | 26 | 14 |
| BIN1 | 18 | 33 |
| BIN2 | 19 | 13 |
| STBY | 4，共用 | 4，共用 |

上电顺序：STBY 保持低 → 设置方向及 PWM=0 → 明确允许后 STBY 拉高。停止测试后先拉低 STBY。PWM=0 的输出行为与 STBY 待机不同，不要把它们都理解成断电。

## 5. 按你 30 排面包板安排信号

工作簿显示 a–e 和 f–j 两组、1–30 排、左右 +/− 轨。**先用万用表确认实物是否每排 a–e 相通、f–j 相通，中央隔槽两侧不通，长轨是否分段**；Excel 图没有证明内部连通性。下表成立的前提是这种标准连通布局。

不用将 ESP32 强塞进这块 30 排面包板；固定在旁边，以短线引到面包板。按 GPIO 标签贴线号。

| 面包板行号 | 左组 a–e：接 D1 | 右组 f–j：接 D2 |
|---:|---|---|
| 3 | PWMA / GPIO25 | PWMA / GPIO27 |
| 4 | AIN2 / GPIO17 | AIN2 / GPIO32 |
| 5 | AIN1 / GPIO16 | AIN1 / GPIO23 |
| 6 | STBY / GPIO4 | STBY / GPIO4 |
| 7 | BIN1 / GPIO18 | BIN1 / GPIO33 |
| 8 | BIN2 / GPIO19 | BIN2 / GPIO13 |
| 9 | PWMB / GPIO26 | PWMB / GPIO14 |
| 13 | AS5600 SDA / GPIO21 | 留空 |
| 14 | AS5600 SCL / GPIO22 | 留空 |

举例：GPIO25→a3，D1 PWMA→e3；GPIO27→f3，D2 PWMA→j3。两组只有 STBY 这一排通过 e6–f6 跳线合并，GPIO4→a6，D1 STBY→b6，D2 STBY→j6，10kΩ 下拉接 c6 到地轨。**不要将其他左右行跨槽相连**。

- 左 + 轨贴“3.3V”，ESP32 3V3 单点接入；右 + 轨贴“5V”，留给已确认需 5V 的逻辑设备。两个 + 轨绝不桥接。
- 两侧 − 轨贴“GND”并桥接；只负责逻辑分配。两板 VCC 接 3.3V 轨，功率地另外回地端子。
- USB 调试时 ESP32 由 USB 供电，断开降压模块到 ESP32 5V/VIN 的供电线。右 5V 轨如要启用，采用一个确认的电源，不把 USB 5V 与降压输出并联。
- AS5600 VCC 沿用“核实模块供电/上拉后再接”的要求；面包板不解决原 R3/5V 上拉矛盾，不能未经确认直接接 5V。SDA/SCL 上拉应到 3.3V。
- 信号按上述行号成束，动力线沿车体两侧走；电机两根线成对绞合，编码器线短、远离电机和 PWM 功率线。接口留少量余量并固定，避免拉力落在插针上。

## 6. 全车集成时的建议

**若只用一个 ESP32，建议补一块 3.3V 的 MCP23017 I2C 扩展模块**，方向和待机走扩展器，4 路 PWM 仍由 ESP32 输出。这是后续增购方案，assets 未显示已有此模块。接法：

| 信号 | 引脚/来源 |
|---|---|
| AS5600 + 扩展器 SDA/SCL | ESP32 21 / 22，共总线 |
| D1 PWMA / PWMB | ESP32 16 / 17 |
| D2 PWMA / PWMB | ESP32 19 / 32 |
| D1 AIN1/AIN2/BIN1/BIN2 | 扩展器 GPA0 / GPA1 / GPA2 / GPA3 |
| D2 AIN1/AIN2/BIN1/BIN2 | 扩展器 GPA4 / GPA5 / GPA6 / GPA7 |
| 两板 STBY | ESP32 33，共用，10kΩ 下拉 |
| 原投掷 IN1/IN2/IN3/EN | 保留 25 / 26 / 27 / 14 |
| PS2 CLK/CS/CMD/DAT | 建议 18 / 4 / 23 / 13；CLK、CMD 改线须同步改固件 |

新增模块应按其具体板型核对地址、RESET、上拉及供电，地址不得与 AS5600 的 0x36 冲突。这是引脚规划，尚未实现新固件。扩展器不能代替硬件急停；I2C 故障时应由主控将 STBY 拉低，停止四轮。该集成方案的面包板行号可保留信号名称，GPIO 来源按本节替换。

另一选择是第二块 ESP32 专管底盘，用第 4 节表；它与投掷主控共地，并另行设计主控间通信与动作互锁。当前资料没有确认已有第二块 ESP32。

## 7. 接完如何验收

1. 全部断电：核对 VCC/VM 未混接、3.3V/5V 轨不短接、输出不接地；按行测通断，核对电机参数。
2. 先只开逻辑电源，VM 断开：测两板 VCC≈3.3V，STBY≈0V；验证 PWM/方向线实际落点。现有 QGPMaker 自检不能验收 TB6612。
3. 对应 TB6612 固件准备好后，架空四轮、拆除投掷负载，采用符合电机电压的限流电源；逐轮短时低占空比点动。记录 FL/RL/FR/RR 的正方向、电流、温升。不要用商品上限替代电机额定值。
4. 验证停止、主控复位、通信断开均使 STBY 低，再验证整车前后/旋转/横移。横移需要四轮独立速度混控；旧 `DRIVE 左 右` 只是差速分组，不能实现完整麦轮控制。
