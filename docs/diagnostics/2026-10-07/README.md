# TB6612 四轮排错记录（2026-10-07）

> **导航**：[仓库总入口](../../../README.md) · [接线与面包板排线](../../麦轮TB6612接线与面包板排线.md) · [底盘主线固件](../../../firmware/chassis/MecanumPS2/README.md) · [诊断固件对照](../../../firmware/chassis/MecanumPS2MotionDiagnostic/README.md) · [第2步逻辑验收](../../../firmware/chassis/TB6612LogicCheck/README.md) · [上位机诊断脚本](../../../host/README-diagnostics.md)

**当前结论：单轮双向和四轮 300ms 正反短测已通过现场观察；四轮持续联动仍未通过，根因未定位。** 本次归档保存诊断实现与证据，不代表整车修复或落地验收完成。

## 现场配置

- 经典 ESP32（ESP32-D0WD-V3），Arduino ESP32 核心 3.3.12，目标 `esp32:esp32:esp32`。
- 两块 TB6612，两线法：PWMA/PWMB 固定接 3.3V；VCC=3.3V；VM 设定 6V。
- FL / RL / FR / RR 的 IN1/IN2 分别为 16/17、18/19、23/32、15/5，共用 STBY=33；PS2 CLK/CS/CMD/DAT=2/4/12/13。
- D1-A=左前，D1-B=左后，D2-A=右前，D2-B=右后。电机只接对应 AO1/AO2 或 BO1/BO2。
- 当前诊断固件为 `firmware/chassis/MecanumPS2MotionDiagnostic/`，轮位顺序 FL,RL,FR,RR，装车极性 `{1,1,-1,-1}`。逻辑正向表示轮胎最上方朝车头运动。
- 后期对照已断开降压模块 5V-OUT 到 ESP32 5V/VIN 的线，ESP32 由 USB 供电，共地及其他线路保留。投掷部分禁用，四轮架空。

## 已测结果与证据边界

串口日志只保存指令、固件状态、主机接收时刻和停止检查。电压与实际转轮情况来自操作员在本次对话中的回报，记录于下列 Markdown 记录中。日志中的 `PASS` **仅表示串口检查通过**，没有电流、电压、转速或轮子运动传感器证据。

| 阶段 | 现场结果 | 判断范围 |
| --- | --- | --- |
| 共地初查 | 表笔底数约 0.2Ω；三个地路径读数 0.3～0.7Ω | 不是加载压降验收 |
| D1-B 同一电机固定占空比 | 约 50.2% / 500ms 不转；约 75.3% / 500ms 双向可启动；63% 的结果有方向差异 | 支持启动占空比影响，未定位唯一根因或精确阈值 |
| 同一电机逐通道对照 | D1-A、D1-B、D2-A、D2-B 在 75.3% / 500ms 双向都可转 | 仅对应当次单轮短测工况 |
| 四台装车电机逐轮 | 四轮分别在 75.3% / 500ms 双向可转；右侧需反号 | 已确认轮位与装车极性 |
| 四轮同时 300ms 正反 | 四轮均转，轮胎最上方分别向车头和车尾运动 | 短测通过，不代表持续联动或地面运动通过 |
| 四轮前进 10 秒请求 | 先右前不转，随后只见左后转 | 实物联动失败；串口状态仍显示四轮指令 |
| USB 相关供电对照 | 动力关、USB 接时 D2 VM=4.87V；拔 USB 后缓慢归零；断开上述 5V 连线后，仅 USB 时 D2 VM=0V | 确认该连线参与电压路径，未确认内部回供机制或全部故障原因 |
| 断开 5V 连线后四轮前进 2 秒 | D2 VM 待机 6V、最低可见 5.6V，只见右后转 | 联动仍失败；万用表不能排除更快瞬态 |
| D2 地差对照 | 相对模块输出 GND 显示 0V，当次没有轮子转 | 不构成四轮实际运转负载下的地线认证 |
| D2 逻辑端检查 | VCC 约 3.3V；PWMA/PWMB 回报符合约 3.3V；GPIO33 动作期间 3.3V、结束归零 | 逻辑电源与动力电源必须区分；未测所有动态波形 |
| D2 STBY 复测 | 初测始终 0V，操作员指出可能接头不牢；插牢后动作期间 3.3V、结束归零 | 初次 0V 不作为已确定线路断点；未确认 D1 动态 STBY |
| 插牢后四轮前进 2 秒 | 仍只见左后转，D2 VM 最低 5.6V | 插牢未使四轮稳定启动 |
| 右前单轮 75.3% / 500ms 再对照 | 能转；最低电压可能 5.9V 或 5.6V，未看清 | 本次最低电压未确认，不做精确比较 |
| **最近一次：降压输入端测量，四轮前进 2 秒** | **待机 12.24V，最低可见 12.16V，只有右前轮转** | **实物联动未通过；可见输入下降 0.08V，不能排除瞬态** |

电池商品页标称 12V、32000mAh、工作电流≤10A；降压模块商品页标称 MP2491C、单路最大 5A。这些是标称信息，未认证实际容量、余量、保护阈值或实物连续/启动电流能力。

最新输入电压证据：[原始串口日志](../../logs/2026-10-07/四轮前进2秒-降压输入电压测量-2026-10-07.txt)，[现场回报与完整过程](麦轮运动组合验收-2026-10-07.md)。最近一次串口流程结束后确认 LOCKED、STBY=0、四輪指令为零并关闭串口；此处不据软件状态推断实体动力开关状态。

## 下一步待测

保持 VM 设定 6V，先测 **降压模块黄色 VADJ-OUT 正极相对模块输出 GND** 的待机电压，以及单次四轮前进 2 秒时的最低可见值。这项还没有执行，目的在于区分模块输出下降与模块到驱动板的配电路径问题。换测点前关闭动力，表笔稳定后再确认通电和待机静止。

此前 D2 VM 最低 5.6V 与输入最低 12.16V 来自不同测试、实际转轮也不同，不能相减作为同期线损。尚未测启动峰值电流、快速瞬态、全部驱动端动态输入/输出和温升；未完成余下九种组合的带动力实测、落地运动或持续遥控验收。没有升压，也没有进行单轮或四轮 100% 带动力测试。
