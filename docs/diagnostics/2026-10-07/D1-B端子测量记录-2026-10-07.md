# D1-B 端子测量记录

日期：2026-10-07。现车两线版；测量值由用户现场读取并反馈，不是串口传感器读数。

## 静止测量

用户按操作步骤通电、以 D1 模块 GND 为参考，依次反馈：

| 测点 | 用户反馈 | 当前判断 |
|---|---|---|
| VM | 6V | 符合本轮 6V 设置 |
| VCC | 3.33V | 符合 3.3V 逻辑供电预期 |
| PWMB | 3.33V | 符合两线版 PWM 输入固定高电平预期 |

本轮测量阶段电机动力线按前述操作保持拆开，尚未发送新的 JOG。上述静止读数不证明输入波形、输出级或负载供电已通过。

## 下一测点

待用户将黑笔接 D1 GND、红笔接 D1 BIN2 并确认放稳后，进行 RL 正向无电机短时重复点动，记录 BIN2；预期接近 0V。之后分别测 BIN1、STBY。

## BIN2 测量窗口已执行

用户确认表笔放好后，在 COM4 执行 RL 正向 duty=128、每次800ms、总时长20秒的重复点动；共发23次，板上返回 OK JOG，状态中 control=JOG、STBY=1、RL指令可达到128，其余三轮指令为0。
结束收到 OK STOP LOCKED，并确认 control=LOCKED、STBY=0、duty=0,0,0,0；脚本正常退出、串口关闭。
仅证明指令接受及软件停止状态；BIN2 实测电压仍待用户回报。

用户回报：BIN2 在点动期间一直接近0V，停止后也保持接近0V。这符合正向RL的非活动方向输入为低、停止时两方向输入归零的预期；未观察到BIN2随正向点动出现明显电压变化。该测量不认证短暂尖峰或完整波形。
下一步：分别测点动期间 BIN1、STBY，仍保持无电机。

## BIN1 测量窗口已执行

用户确认红笔移到 BIN1 并放好后，在 COM4 执行同条件 RL 正向无电机重复点动20秒，共23次。板上返回 OK JOG，RL指令有软启动并达到128；结束收到 OK STOP LOCKED，脚本正常退出。
BIN1 点动期间及结束后的实际电压待用户回报。

用户回报：BIN1 点动期间读数跳动，最高约1.6V；开始前与结束后均为0V。与本轮正向输入软启动/重复点动、停止归零的行为相符，支持控制变化已到该模块测点；普通万用表仍不能认证PWM频率、幅值峰值或完整波形。
结束后另行仅发送STATUS，连续确认 control=LOCKED、STBY=0、duty=0,0,0,0，串口关闭。
下一步：测模块端 STBY 在同条件点动期间和停止后的电压。

## STBY 测量窗口已执行

用户确认表笔放好后，在 COM4 执行同条件 RL 正向无电机重复点动20秒，共23次。串口开始读到启动文本与初始 ps=0，随后 ps=1 且命令被接受；未据启动文本判定复位原因或发生时刻。
点动采样状态 STBY=1、RL指令可达到128；结束收到 OK STOP LOCKED，最后状态 control=LOCKED、STBY=0、duty=0,0,0,0，脚本正常退出并关闭串口。
模块端 STBY 实测电压待用户回报。

用户回报：STBY 点动期间跳动，最高约3.3V，结束后归零。与有效点动使能高、间隙及停止归零的预期相符。

恢复6V VM后，以D1 GND为参考，用户依次报告BO1=6V、BO2回复“o”（本轮按0V理解，待用户有异议时更正）。
当前结果支持D1-B能在无电机、固定正向输入下建立高低输出；不认证负载驱动能力、反向通路或原PWM状态。原“不转/输出0V”故障尚未解决。
下一步：先全部断电，再交换BIN1/BIN2固定高低输入，复测空载反向输出。

## 空载固定反向输入测试

用户确认全部断电后，交换BIN1/BIN2的临时跳线：BIN1接GND、BIN2接3.3V，STBY保持接3.3V。USB逻辑供电后、VM关闭时，用户确认两方向输入符合低/高预期，未提供具体电压。

正向6V/0V、反向0V/6V均符合空载直流预期；不据此认证带载能力或原PWM控制已正常。此前PWM输出0V和电机不转仍须复现定位，不能宣布故障已经解决。

## 后续负载短测准备（尚未执行）

先全部断电。为避免固定STBY高时电机持续运行，计划将D1 STBY临时3.3V跳线拆下，恢复其原GPIO33共用STBY控制支路；BIN1低、BIN2高的静态方向先保留。

## 固定反向输入、带电机500ms短测已执行

用户恢复D1 STBY原GPIO33控制，USB仅逻辑供电时现场测STBY=0V；断电后将此前直供能转的电机接D1 BO1/BO2。BIN1仍固定GND、BIN2仍固定3.3V，PWMB仍3.3V，原GPIO18/19控制线与模块输入保持断开。用户恢复供电后报告电机不转（待机状态）。
重新插USB后端口由COM4变为COM5（CH340，VID:PID=1A86:7523）；COM4打开失败，未发点动。改用COM5，仅STATUS预检，确认hw=1、ps=1、buttons=0000、LOCKED、STBY=0、四轮指令0，随后只发送一次JOG RL 128 500。
板上接受命令，采样到STBY=1（指令占空比15不代表本次电机真实占空比），随后自动JOG DONE/STOP；另发STOP与STATUS，确认LOCKED、STBY=0、四轮指令0，串口关闭。
本次模块输入为固定反向、全直流驱动，仅STBY限时使能约500ms；现场是否转动待用户回报。未使用20秒重复脚本。

用户回报：电机转了约半秒，与500ms限时使能相符。该配置已验证D1-B可短时驱动这台电机；未测启动峰值电流、动态压降、长期温升、其他电机/通道或整车负载。
静态方向输入与GPIO33限时STBY组合能够驱动，是反对“D1-B完全无驱动能力”的证据；不能据此断定原PWM链路或所有接触均正常，也不能定位先前问题唯一原因。
下一步计划：全部断电，拆下BIN1/GND、BIN2/3.3V临时跳线，恢复GPIO18→BIN1、GPIO19→BIN2，STBY继续原GPIO33；保留同一电机和6V。先在原接线下用单次反向JOG RL -128 800测试，以保持与刚才固定输入相同的物理方向。该测试含约430ms爬升、剩余约370ms目标平台；不转不能单独证明控制故障，须与启动占空比不足区分。尚未执行。

## 原两线版 PWM 接线恢复后，反向800ms短测已执行

用户确认断电后移除临时BIN1/GND、BIN2/3.3V跳线，并恢复面包板GPIO18→BIN1、GPIO19→BIN2支路；STBY保持GPIO33控制，保留同一台电机。用户恢复USB与6V供电后反馈电机静止。

现场是否转动待用户回报。未重复点动、未改固件，也未把指令占空比当作端子实测波形。

用户回报：原接线下本次反向PWM短测电机没动。
