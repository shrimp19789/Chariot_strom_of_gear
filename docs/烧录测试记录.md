## 结论与限制

串口、两个阶段的编译、第一阶段上传和启动均通过。编码器初次读取正常，但动态采集时通信失败，复位后依旧无应答；编码器测试未通过。

初次 ML=1 表示传感器报告磁场偏弱。动态采集没有有效角度，无法判断整圈范围、回绕或运动时磁场状态。现象提示接线或供电不稳定，但不能仅凭这些读数证明线断或芯片损坏。优先断电检查 GPIO21 到编码器 SDA 的通断及接触，再检查 VCC 和 GND；通信恢复后核对磁铁距离与对中。

尚未执行电机校准或带电试转，第二阶段配置保持 CONFIG_CONFIRMED=false。板上保留第一阶段诊断固件，串口读取结束后已关闭。

## 工具问题

原 MCP 串口读取函数收到数据后会把截止时间延长 0.4 秒，持续输出会导致读取不返回并占用串口。USB 重插后占用释放，本次后续验证使用固定截止时间的独立脚本，读取结束后关闭串口。未修改原项目和 MCP 服务源码。
