# 两线TT电机与麦轮分层验收

日期：2026-10-06。依据：[TT电机测试方案](TT电机测试方案.md)第8节及[现车接线](麦轮TB6612接线与面包板排线.md)。用户已确认每台仅2根动力线、额定3–6V、标称空载电流140mA，VM从12V降至3V；无编码器。140mA对应的标称电压尚未提供。

本文是针对现车重设计的操作单，不代表以下项目已通过。本次已发送STOP，串口确认LOCKED、STBY=0、四轮指令为0；未新增运动测试、未更换固件。

## 1. 修正原测试的适用范围

- 不执行原文第3–7节的编码器接线、手转CPR标定及中断计数，不接GPIO18/19：这两脚已用于D1-B电机控制。
- 不将585/624 CPR、245/355rpm或原文典型堵转电流当作当前电机规格。原文所指配套encoder `.ino` 未在项目中找到，且不适用于这批两线电机。
- 不强行反拖减速箱，不通过未知线短接来识别电机。不执行手卡轴堵转测试。
- 外壳温度需要时用测温工具记录；不通过“能摸几秒”推算摄氏温度。
- 此前3V、64/255点动400ms用户反馈不转。后一次目标128/255、400ms仍含每10ms增3档软启动，从零达到128至少约430ms，未形成50%平台，现场结果尚未明确。不能据此认定电机、接线或驱动损坏。
- 本检验先使用实际直流3V，PWM验收另做。程序指令、GPIO回读均不能证明远端电压、真实电流或轮子转动。

## 3. A阶段：单台电机独立供电

目的：将ESP32、PS2、TB6612和面包板排除在本次电机启动检查之外。需要现场操作，串口无法代做。

1. 断开VM、USB及其他电源。选M1，拍照/标记原端子，将它的两根动力线**都从TB6612输出上拆开**。不能在电机仍连着AO/BO时并接外部电源。
2. 固定电机或车架、轮子架空。若拆掉轮子更方便，可只测试电机减速输出轴；记录是否带轮，以免把架空带轮电流等同裸电机空载电流。
3. 独立可调电源空载设为3.0V，用电压档复核。优先用具备限流与电流显示的电源，记录实际限流设置；未知限流不填为140mA，空载电流不是启动电流。本阶段电源只接电机两根线，不需要与ESP32共地。
4. 经可操作开关给M1通电约0.5–1秒，立即断开，观察有无启动、异响、明显电压下降及电源CC/保护指示。没有转动不保持通电等待，不带电抓轴。
5. 若不转：先记录电机两端实际电压和电源是否进入限流。输出电压塌陷时先查电源、限流、导线和连接；电压正常仍不转时再查接触/电机机械状态。不能直接判定坏电机，也不盲目提高限流。
6. 只有供电/连接正常且无异常，才可在已确认3–6V规格范围内，按3V→4.5V→6V逐级进行同样短测，逐级记录；不要回到12V。若已在3V正常启动，无需为“看它转”继续升压。
7. 正向启动正常后，断电、等停稳、交换电机两根线，再短测反向。最后全部断电。

通过条件：某个记录清楚的额定范围电压下正反向均能自主启动，无卡住、明显异常声或供电保护。只通过短时启动，不宣称寿命、堵转能力或驱动板通过。

**记录：** M1；带轮/裸电机____；设定电压____V；电机端电压____V；电源限流____A；CC/保护____；转动____；方向____；电流显示____A；持续____s；异常____。

## 4. B阶段：TB6612单通道与已验证电机

A阶段通过后再做。全部断电，把已知能转的M1接回记录的一个通道，其他电机动力线暂时隔离并标记。恢复现有共地；VM使用A阶段已验证、且满足驱动模块要求的3–6V电压。逻辑VCC/PWMA/PWMB继续3.3V，不能改成电机VM。

先复测驱动板端VM、VCC、PWMA/PWMB和待机STBY。已有3.2/3.2/3.2/0.4V是历史用户读数，不当作本阶段实时测量。

本阶段应使用专用单通道验收固件，要求如下（**尚未实现/烧录，不能把下面当现有串口命令**）：

- 启动、停止和故障拉低GPIO33；投掷14/25/26/27保持低。不依赖PS2或AS5600，先单独验证驱动链路。
- 同时只允许一个通道输出；方向与持续时间必须显式给定；单次直流输出最长1秒，到时撤销STBY并锁定，复位不恢复。
- 首测可在已验证的3V电源下给短时100%方向输出，明确IN1=高、IN2=低（反向相反）、板上PWM恒高，消除低PWM启动能力不足的歧义。这是待执行的方案，不是已执行结果；若M1只在较高电压通过，先按该电压重新核对驱动与供电。
- 串口输出开始/结束时间、通道和设定值。保持STOP命令、非法命令停机、通信租约/硬超时和看门狗；不提供无限时保持使能。
- 示波器/逻辑分析仪用于观察驱动板端STBY/IN波形；万用表慢刷新可能漏掉1秒脉冲，读0不能单独证明无输出。不为方便读表而无限延长不转电机的通电时间。

| 观察结果 | 下一步定位 |
|---|---|
| 独立直供能转，通过驱动不转 | 查驱动板端VM是否掉压、STBY是否实际拉高、IN是否到板、PWM/VCC与共地 |
| MCU端变化，板端不变化 | 查连接路径和端子接触 |
| 板端控制符合预期，输出不符合 | 核对模块引脚、保护/损伤、输出连接；换已知正常通道交叉验证，均在断电后改线 |
| 驱动输出到电机端正常仍不转 | 查电机连接、受载状态及供电动态；与A阶段同条件比较 |

通过后将同一台已知正常电机依次用于其余通道，可区分通道与电机问题；再接回M2–M4逐台验证，避免四轮同时试转掩盖故障。

## 5. C阶段：PWM、轮位和方向

只有B阶段通过后进行。固定VM为已验证电压，试25%、50%、75%、100%等阶梯，分别记录能否从静止启动及稳定转动；先短测，有异常就停，不以占空比推算转速。

软启动时间和目标保持时间要分开记录：现固件每10ms增3档，到128约430ms。因此任何后续测试须明确“总时长”还是“到目标后的保持时长”，不能声称400ms测到了稳定50%。后续固件仍需总时长硬上限。

标定每个通道对应的真实电机和“驱动车体向前”的极性，再修改POLARITY。核对麦轮左右手安装后才检验横移。反向前撤销输出并观察停稳；固定300ms等待不是机械停稳证据。

## 6. D阶段：PS2与整车功能

恢复MecanumPS2。首先架空检查：启动不动→START解锁→L1+方向短按→松L1停→圆圈锁定→重启不恢复。再验证前后、横移、旋转，记录各轮方向。

在低速架空状态关闭手柄，验证实际接收器断联会停车且重新连接不自动运动。仅有协议有效帧不能证明无线手柄仍在线；本项必须现场实测。检查物理VM断电开关。全部通过后再低速落地。

主动短路制动另做，现有固件未实现该项；不将滑行停止记作制动通过。AS5600及投掷保持排除。

## 7. 电流、转速和温升补测

- 正反短测及供电通过后，逐步延长无异常运行至5秒、30秒，再按需要做2分钟温升观察；每阶段通过后才进入下一阶段。
- 优先读电源显示并注明是否捕获启动峰值；普通显示的平均值不能替代启动/堵转峰值。需串联电流表时先断电、核对表笔插孔和有保险丝的合适量程，电流档不得并接电源。
- 140mA仅是用户给出的标称空载值，测试电压、带轮状态不同不能硬套。记录实测条件，必要时与同批其他电机比较，不沿用原文0.08A/0.2A作判据。
- 无编码器不输出伪rpm。需要时在轮轴作一个可辨标记，用视频中实际拍摄时长t秒和完整转数N计算rpm=60N/t；慢动作播放时长不是实际拍摄时长，且需避免漏圈/混叠。
- 不进行人为堵转；堵转规格优先查具体型号数据。
