## 一、原理（一句话）

**编码器就是一个"角度计数器"**：
- 电机每转一点点，A、B 两相就输出脉冲；
- **数脉冲 = 数角度**；**脉冲的快慢 = 转速**。

所以只要知道"**输出轴转一圈有多少个脉冲**"（记作 **CPR**），圈数和转速就都能算。

```
圈数   N    = 累计脉冲数 ÷ CPR
转速   rpm  = (Δ脉冲数 ÷ CPR) × (60 ÷ Δt秒)
```

---

## 二、三个公式（背下来就够了）

| 要算什么 | 公式 | 说明 |
|---|---|---|
| **每输出圈脉冲（CPR）** | `CPR = 编码器线数 × 减速比` | 指**单相上升沿** |
| **圈数** | `N = 脉冲数 / CPR` | 用**单相** A（或 B）的计数 |
| **转速** | `rpm = (Δ脉冲 / CPR) / Δt × 60` | Δt 是测量窗口（秒） |
| 用 4 倍频计数时 | `N = |4x| / (4 × CPR)` | `|4x|` 取绝对值（带符号的是方向） |

**两个口径别混：**
- **单相上升沿**：每圈 = `线数 × 减速比`（**程序里的 `CPR` 就是这个**）
- **4 倍频计数**：每圈 = `线数 × 减速比 × 4`（厂家的"每圈最大计数"常用这个口径）

## 四、怎么读：两种模式

| 模式 | 命令 | 给什么 | 需要通电吗 |
|---|---|---|---|
| **定圈标定** | `c` → 手转整 N 圈 → 敲 `N` | **CPR**（最准） | ❌ 不需要（手转就行） |
| **实时转速** | `s <CPR>` → `v` | **rpm**（每 0.5 s 一行） | ✅ 需要（直驱或驱动板） |

**典型流程**：
```
① 手转标定拿到 CPR      → c → 10 圈 → 10     （重复 正2 + 反2 轮）
② 把 CPR 填进去          → s 585
③ 通电读转速             → v
```

**串口输出长这样**：
```
[转速]   176.0 rpm   (dr=858/0.50s, CPR=585.0, 占空比=50%, 非法跳变=0)
        └ 转速            └ 窗口内脉冲数    └ 你填的CPR   └ 状态      └ 应为0
```

## 五、手算示例（可以照着核）

**例 1：算转速**
```
窗口 Δt = 0.50 s，A 相数到 858 个脉冲，CPR = 585
  圈数 = 858 / 585 = 1.4667 圈
  转速 = 1.4667 / 0.50 = 2.933 圈/秒
       = 2.933 × 60 = 176.0 rpm
```

**例 2：算 CPR（手转）**
```
手转 10 整圈，A 相数到 5850 个脉冲
  CPR = 5850 / 10 = 585
```

**例 3：用 4 倍频反算**
```
4x 计数 = 23400（绝对值），CPR = 585
  圈数 = 23400 / (4 × 585) = 23400 / 2340 = 10 圈 ✓
```

**例 4：按占空比估"等效电机电压"**（用 TB6612 + 12V→6V 降压时）
```
进 VM 电压 = 6.0 V，占空比 50%
  等效电机电压 = 6.0 × 0.50 = 3.0 V   （对应转速大约是一半）
```
> ⚠️ 比较转速时必须**同电压口径**：标称 355rpm 是 **6V** 下的；你占空比 100%（等效 6V）时才有可比性。

## 六、误差从哪来（这一节最实用）

| 误差源 | 影响 | 怎么压 |
|---|---|---|
| ⭐ **手转起止没对齐** | **CPR 的主要误差**。少转 30°（≈0.08 圈）→ 10 圈时约 **0.8%** | 固定起止标记；**改转 30–50 圈**（相对误差降到 ~0.3%） |
| **窗口量化** | ±1 个脉冲。窗口内 858 个脉冲 → ±0.12% | 窗口越长越准（0.5 s → 1–2 s） |
| **CPR 本身不准** | **按比例传导到转速**：CPR 差 1% → 转速也差 1% | 先把手转 CPR 标定准 |
| **手转时来回晃动** | 有符号净位移 `q` 加加减减 → 比值失真 | **一轮只朝一个方向转** |
| **接触不良** | 读数乱跳、偶发丢脉冲 | 焊点/插头检查；**数值乱跳先怀疑接触** |
| **高速丢沿** | 转速偏低、`dr` 波动大 | 看"`非法跳变` 是否 0 + rpm 是否稳定"；必要时做压力自检 |

### 三个"体检指标"（每次标定都看）

| 指标 | 合格 | 不合格说明什么 |
|---|---|---|
| `abs(4x)/A`、`abs(4x)/B` | **接近 4.000**（3.97–4.03） | 偏离 → 丢边 / 混入反向 / 相位异常 |
| `A` 与 `B` 的差 | **≤3**（起止边界的正常差） | 差很多 → 某一相丢计数 |
| `非法双位跳变 j` | **0** | ⚠️ **`j=0` 不证明没有丢计数**（漏掉整组周期也可能不产生非法跳变）→ 还要看"**同方向两轮 CPR 是否一致**" |

> 🔴 **一条实测教训（来自 MD520 现场）**：`4 × A − |q|` 这个差在理想情况下应很小（≤4）。若明显超界（当时实测 25–53），说明**存在回转行程 / 抖动 / 采集问题**，**那一轮的 CPR 不要急着用**，先复测。

## 七、判据（TT 电机）

| 项 | 判据 |
|---|---|
| 两相脉冲 | **A、B 都必须有**（只有一相 = 缺通道，先查线序/引脚，别直接判坏） |
| `abs(4x)/A`/`B` | 接近 **4.000** |
| 方向符号 | 正转与反转的符号**必须相反** |
| 同方向两轮 CPR | 应一致（差异主要来自起止对齐） |
| **空载转速** | 6V 下 **≈355rpm**（1:45 版）/ ≈245rpm（1:48 版），允差 ±10–15% |
| 4 倍频/圈 | ≈2340（13×45）或 2496（13×48） |

## 八、常见坑（都是现场踩过的）

| 坑 | 正确做法 |
|---|---|
| **转着转着忘了圈数** | **重敲 `c` 重来**，**不要猜数字**（那个数是 `CPR = 脉冲/圈数` 的除数，猜错整轮废） |
| **想用脉冲反推圈数**（`脉冲 ÷ 585 ≈ 圈数`） | ❌ **循环论证** —— 这样算出的 CPR 恒等于你假设的值，标定失去意义 |
| **中途停下歇手** | ✅ **可以**（静止不产生脉冲，计数是累积的）；唯一禁忌是**反向晃** |
| **通电后 rpm 一直是 0** | ⭐ **没共地**（电源负极 ↔ 控制器 GND） |
| **串口打开是空的** | 程序只在开机打印横幅 → **按一下复位键（`EN`）**；或用带心跳的程序 |
| **量线时"很多线对都响"** | 线缆**两端都拔开**再判通断；接着电机时绕组会让很多对"响"，属正常 |
| **编码器线颜色** | **不能猜** —— 看电机 PCB 丝印 / 卖家线序图 |

## 十、没有编码器怎么办（仅当 TT 电机只有 2 根线）

**"数圈读转速"这套不成立**（没有脉冲可数）。替代：

| 方法 | 能得到 |
|---|---|
| **手机慢动作视频**（240fps）拍 10 秒，回放数圈 | 粗算 rpm（±10% 量级） |
| **反电动势**：万用表直流 mV 档接两根动力线，手转轴 | 绕组/碳刷是否正常（定性） |
| **空载电流**（串电流表） | 典型 0.1–0.25A；偏大 = 异常 |
| **齿轮箱手感 / 声音** | 卡顿、异响、旷量 |
| 要精确转速 | 加装光电/霍尔测速，**或换带编码器的版本** |
