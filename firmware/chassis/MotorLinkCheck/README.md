# MotorLinkCheck：奇果派 PCA9685 链路自检（固件 1）

> ⚠️ **本固件只适用奇果派 QGPMaker 驱动板（PCA9685 @ I2C `0x60`），烧到 TB6612 上不会有任何反应。**
> 底盘当前方案是 [2 × TB6612FNG 两线法](../../../docs/麦轮TB6612接线与面包板排线.md)。
> 本目录保留是因为该方案仍是**需要舵机时的备选**（8 路舵机 + 4 路电机只占 2 根 I2C）。

## 它比「扫描 I2C 地址」强在哪

I2C 扫描只能证明"某个地址上有东西应答"，总线干扰或别的 I2C 器件都可能误判。
本固件会往 PCA9685 的 `MODE1` 寄存器**写已知图案再读回来比对**（自动递增位、SLEEP 位），
写进去什么就读出什么，才判定驱动板真的在线。

## 串口命令（115200 8N1）

| 命令 | 作用 |
|---|---|
| `CHECK` | 完整自检并打印报告（**开机自动执行一次**） |
| `SCAN` | 只做 I2C 全总线扫描 |
| `TEST ALL` / `TEST <1-4>` | 依次 / 指定点动电机 |
| `M <1-4> <-255..255>` | 手动驱动某路（正=正转，负=反转，0=停） |
| `STOP` | 全部停止 |
| `I2C <sda> <scl>` | 改用自定义 I2C 引脚并重新自检（仅 ESP32 有效） |
| `HELP` | 帮助 |

报告会**区分三种失败原因**：总线被拉死/无上拉（超时>0）、总线好但无器件应答（只 NACK）、
总线上有器件但不是 PCA9685（地址被改过或接错）。

## 可选的 C 层电流检测

这块驱动板**没有电流检测电路**，所以软件无法感知"电机线圈到底接没接"。
本固件内置了可选的第三层检测，在源码顶部打开即可：

```c
#define SENSE_PIN      34      // ACS712 输出接到 GPIO34
#define SENSE_MV_PER_A 185.0f  // ACS712-05B 是 185mV/A；20A 版填 100，30A 版填 66
```

接好后点动测试会打印「电流 xx mA → 检测到电机 / 疑似未接电机」。**在此之前以点动观察为准。**

## 上位机

```powershell
python host\motor_link_check.py          # 自动认串口、复位抓自检、主动发 CHECK、给中文结论
```

## 构建 / 烧录

```powershell
.\tools\build-chassis.ps1 -Sketch MotorLinkCheck -Upload
```

默认 FQBN `esp32:esp32:esp32`（通用款）；其它板型加 `-Fqbn`。**本固件依赖厂家库 `QGPMaker_MotorShield`。**
