# 双TB6612麦轮＋PS2独立底盘

适用于经典ESP32及Arduino ESP32 3.3.12。接线按 `docs/麦轮TB6612接线与面包板排线.md`：FL=16/17，RL=18/19，FR=23/32，RR=15/5；共用STBY=33及外部10kΩ下拉；两板PWMA/PWMB固定接3.3V。PS2 CLK/CS/CMD/DAT=2/4/12/13。八路LEDC通道0–7，20kHz、8位；本程序不加载SimpleFOC，不代表未来投掷集成时资源已核对。

AS5600不参与控制，投掷14/25/26/27保持低。首次验证四轮架空、投掷动力断开，电机额定电压与VM匹配并采用合适限流；首次轮位、正负极性和麦轮左右手安装必须核对。

## PS2操作

1. 开机默认LOCKED。先松开所有按钮，手柄连接有效后，单独按一次START解锁（或串口发送 `PS2`）。
2. 按住L1，同时按方向键：上/下=前后，左/右=横移；L2/R2=逆/顺时针旋转。支持组合输入并归一化。当前使用数字按键，不使用模拟摇杆。
3. 松开L1立即撤销STBY；方向释放时PWM逐步减至0。圆圈键或串口 `STOP` 锁定，需要再次START解锁。
4. PS2无效帧或150ms无新有效帧将锁定；恢复通信不会自动恢复运动。无线接收器若在手柄断电后仍伪装有效旧帧，协议检查无法识别，必须实测该接收器断联行为。

初始PWM上限76/255≈29.8%，每10ms最多变化3档。占空比不是转速或电流限制。换向先减到0，再等待至少300ms才反向；这个固定等待不是电机已静止的传感器证据。停止为高阻滑行，不是主动制动。本版未实现主动短路制动。

轮位顺序为FL、RL、FR、RR；`POLARITY`初始全为+1，按每轮“驱动车体向前”的方向标定后修改。未核对极性和麦轮安装前，不保证横移/旋转符合按键方向。

## 串口115200，命令以换行结束

| 命令 | 作用 |
|---|---|
| `STATUS` | 查看硬件初始化、PS2、模式、STBY及四轮指令占空比；不代表实测轮速 |
| `STOP` | 立即撤销STBY并锁定 |
| `PS2` | 在PS2稳定且所有按钮松开时解锁遥控，不立即运动 |
| `JOG FL 64 400` | 左前正向64/255，限时400ms，含加速过程 |
| `JOG RL -64 400` | 左后反向点动示例 |

v1.1在用户报告VM已降至3V后，将单轮JOG上限改为128/255（约50%），PS2上限仍为76/255。固件没有VM采样，不能自动识别实际电压。

JOG只接受FL/RL/FR/RR、非零±1..128占空比、50..800ms。需控制模式LOCKED、PS2在线且按钮松开；正在点动或PS2模式时拒绝再点动。到时、PS2断联或任意按键立即停止并锁定。串口断开无法瞬间检测，但点动不会超过限定时长；PS2模式独立于串口运行。

每轮从短时低占空比开始，观察不转时先STOP并检查供电/接线/机械阻力，不自动提高占空比。轮间留出观察间隔，不同时给四轮发测试序列。记录实际轮位、方向、电流和温升。

设置1秒任务看门狗，主循环停滞将触发panic；启动保持禁用。看门狗实物行为及复位期间STBY瞬态仍待测试，软件不能代替物理断电开关。

## 验证

主机测试 `tests/test_mecanum_drive_math.cpp` 验证四轮混控、幅值上限、零输入、换向零输出等待、STOP保留方向历史及时间回绕。Arduino编译检查真实核心API，烧录后另查串口硬件初始化和PS2状态。尚未现场确认的轮子运动不得记录为通过。
