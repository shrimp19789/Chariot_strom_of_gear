# Stage1_AS5600Test：第一阶段（只读编码器 + I2C 电气诊断）

> **导航**：[仓库总入口](../../../README.md) · [ESP32-2804 接线与烧录指南](../../../docs/ESP32-2804-FOC-guide.md) · [诊断记录-第一阶段](../../../docs/诊断记录-第一阶段.md) · [投掷机构-设计与安全](../../../docs/投掷机构-设计与安全.md) · [主固件 PS2Catapult](../PS2Catapult/README.md) · [Stage2](../Stage2_FOCClosedLoop/README.md)

第一阶段：**只读 AS5600 磁编码器，不驱动电机**，并把 EN 拉低。在原程序上加了两点诊断：
找不到 `0x36` 时**自动扫描全总线**（区分"线没通"还是"地址不对"），以及打印 `changes` 计数
（判断磁铁是否真的随转子在动）。

> ⚠️ **前提：请断开驱动板功率电源（8.2–24V 输入）**，只留 USB 给 ESP32 供电。本程序不驱动电机。

## 正常表现（guide 第 4 节）

```
raw=1234  deg=108.46  MD=1  ML=0  MH=0  changes=57
```

- 手慢慢转一圈，`raw` 大致走满 **0~4095**，跨零点正常回绕
- 转子不动时读数基本稳定
- `MD=1` 检测到磁铁；`ML=1` 磁场偏弱；`MH=1` 磁场偏强（**MD=1 且 ML=1 → 程序拒绝使能**）

## 串口命令（115200）

| 命令 | 作用 |
|---|---|
| `P <sda> <scl>` | 换一对 I2C 引脚重新诊断（排除"引脚不对 / SDA 接反"） |
| `W` | **连续监视**（每秒扫一次总线）：一边晃动/重插线一边看器件数，抓接触不良 |
| `G` | **扫描所有 GPIO**，找出哪个引脚接了外部上拉 —— 判据：**`共 2 个引脚有外部上拉`** |
| `L` | 低速重试（50kHz / 10kHz）+ 强制内部上拉（排除上拉太弱） |
| `S` | 重新扫描总线 |
| `H` | 帮助 |

> `G` 必须在**启用内部下拉**的条件下读。只用 `pinMode(INPUT)` 读悬空脚会得到**随机假高电平**
> —— 早先那次误判就是这么来的（见 [诊断记录](../../../docs/诊断记录-第一阶段.md) 第四节之二）。

## 构建 / 烧录

```powershell
.\tools\flash-catapult.ps1 -Stage 1              # 检测串口 → 认芯片 → 编译 → 烧录 → 读回
.\tools\flash-catapult.ps1 -Stage 1 -CompileOnly # 只编译
```

依赖 `Simple FOC 2.4.0`（库名有空格）与 `esp32:esp32` 3.3.12。
