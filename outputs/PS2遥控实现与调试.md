# PS2 遥控投掷杆：实现与调试

## 交付范围

带中文注释的 Arduino 源码：PS2Catapult/PS2Catapult.ino。ESP32 core 3.3.12、Simple FOC 2.4.0；无需安装 PS2X 库。采用通用 PS2 数字按键协议，TK-PS2A 型号的厂家协议资料未查到，需实机验证，并非已确认兼容。

默认 CONFIG_CONFIRMED=false、SUPPLY_VOLTAGE=0：驱动EN保持低，仅打印PS2与编码器状态。仅用于低速原型验证，不代表已实现可靠投掷或硬件安全限位。

2026-10-05已将程序上传COM9并验证启动，随后增加d编码器诊断命令并再次编译上传：程序332524字节（25%）、全局变量24548字节（7%），上传哈希校验通过。默认电机锁定未更改。PS2数字模式41的数据帧已验证；按键功能、自动往返、带杆运行尚未验证。

## 当前问题并未消失

模块端的3.3V与ESP32侧的GPIO21低电平不能互相替代。先断电测四根线两端通断，再核对逻辑电压。此前编码器曾成功读角度但随后持续I2C错误，且成功时ML=1。新代码要求MD=1、ML=0、MH=0，磁场过弱会拒绝使能。

“5V区第二个接ESP32、第三个接驱动板”不能确定每根是5V还是GND。降压板照片可辨认5V-OUT、3V3-OUT、VADJ-OUT，但排针某个位置不能仅凭左右顺序判断。驱动板功率输入照片标8.2~24V：如果实际从5V输出取电，需要改正。供电输出、电机与驱动板额定范围必须同时满足。

GPIO2、GPIO12是ESP32启动配置引脚；TK-PS2A外设上电时的电平可能干扰启动，尤其GPIO12。遇到启动/下载问题，优先改CLK到18、CMD到23并同步改代码，不盲目重烧。蓝牙/无线手柄接收器的无线制式不是本代码前提，MCU侧使用CLK/CS/CMD/DAT四线。

## 控制原理

蓄力不是实际存储弹簧能量，而是记录按键时长：

speedCap = 0.3 + (1.5 - 0.3) × min(按住毫秒 / 3000, 1)，单位rad/s。

满3秒后保持上限，100毫秒内的点击被忽略。保持L1，按住×开始蓄力，松开×才开始动作；蓄力阶段电机保持原点。动作期间新蓄力被忽略，复位完成后才接受下一次。

状态流：READY → CHARGING → FORWARD → DWELL(300ms) → RETURNING → READY。

正向参考轨迹从0到π/2；按2 rad/s²限制参考加速度，按所选速度限制参考速度，剩余距离不足时按 sqrt(2×加速度×剩余角度)减速。到位需角度误差小于1度、角速度低于0.1 rad/s并持续200ms。返回上限0.3 rad/s。动作超时15秒进入故障。

SimpleFOC角度控制器以编码器角度为反馈，把参考角度变成速度需求，再通过速度环生成FOC电压。更新速度限制同时更新库内部控制器限制，电压上限为1V。PID为初始值，必须实机整定；电压限制不等于电流限制。

按住时间增大只提高速度上限，不保证实际最高速度单调增加。90度行程的加减速距离、负载惯量、驱动电压和扭矩都会限制实际速度。球速还取决于杆长、球脱离角度和装球机构。本版会在90度前减速，不保证在90度位置以最高速度出球；若需求是端点高速释放，需要另设计释放角与制动余量，不能要求在同一点高速运动且瞬间停止。

故障处理：编码器读失败、磁场异常、PS2数据不合法、帧超时、动作中松L1、按○、超时、检测到角度越界都会禁用驱动。故障时不盲目自动回零。禁用后电机可能惯性运动或受重力下落，必须有独立硬限位和物理断电急停。

无线失联时若接收器持续回传旧的合法帧，软件帧超时无法识别；必须实测手柄关机/电池取出/接收器掉电行为。不能把L1或○等同于独立硬件急停。

## 编码器零点与调试顺序

1. 驱动功率保持断开，先运行默认锁定代码。检查PS2=1，按L1、×、○观察buttons变化；enc=1、magnetOK=1并手转角度检查。锁定状态尚未设置机械零点，arm显示0，不是角度恒定的证据。

   串口发送d可检查GPIO21/22自由电平、内部下拉/上拉后的电平，尝试开漏时钟与STOP总线恢复，并在100/50/10kHz读取编码器。仅在电机禁用时可用。电平结果不能单独证明线断或导通。
2. 修复供电：确认ESP32实际5V/VIN与GND落点、驱动功率输入及极性、编码器逻辑供电；测驱动板输入电压并填SUPPLY_VOLTAGE。不要把5V逻辑输出当驱动功率输入。
3. 卸下投掷杆和小球，再按项目条件修改CONFIG_CONFIRMED=true，重新编译上传。
4. 串口115200发送c，仅在卸杆条件下执行FOC对齐；这一步可能旋转超过90度，而且阻塞期间软件急停不保证响应。
5. 校准后驱动禁用。断开驱动功率再安装杆，将杆置于机械原点；恢复已确认的功率供电并发送h记录当前编码器角度作为0度。h是人工置零，不是自动找限位。重启后需要重新校准/置零；以后应增加原点开关和可验证的校准保存流程。
6. 松开所有手柄按钮，再发送a使能。保持L1，短按×再松开×，低速验证正方向、90度目标、返回和故障处理。任何异常先物理断电。
7. 无球机构验证后再使用轻软球测试，记录实测角速度、电流、温升、超调与释放角。依据机械强度和实测结果调整；不要直接提高电压或速度。

## 距离投石小车还缺什么

- 编码器稳定通信与磁场状态验收、供电落点及额定范围确认。
- TK-PS2A按钮映射、启动兼容性、无线失联与恢复测试。
- 0/90度独立机械限位、缓冲、原点开关、断电急停；必要时加保持制动，FLT接线与电流监测。
- 杆长、质量、球质量和安装方式；计算扭矩与惯量，确认2804适用。静态重力扭矩约m×g×重心到轴距离，动态还需J×角加速度；资料给的0.03N·m不能当全转速连续可用扭矩保证。
- 小球托座/释放机构、防止复位时带球、护罩和稳定底座。
- FOC参数整定、角度/速度跟踪与刹停验证；软件目标夹在90度不保证实际不超调。
- 小车底盘、轮电机和匹配驱动器、转向/差速、车体供电，以及与投掷状态互锁。本程序仅控制投掷电机，不控制行驶。

下一步优先做“供电与编码器验收 → 手柄独立验收 → 卸杆校准 → 低速空载往返 → 机械限位/负载验证 → 轻软球释放验证 → 底盘集成”。
